    Usage, Case, Example, Howto
    المورّد Alpha Export LLC يصدر لك فواتير بعملتي EUR وUSD.

    1. إعدادات سجل الأطراف → نوع الطرف (الجدول)#

      Supplier → Allow Multi Party = ✅، Rule Field = default_currency

    2. انتقل إلى Party Master، سجل Alpha Export LLC#

      أنشئ طرفًا جديدًا (الافتراضي Supplier) → العملة = EUR → حفظ.
      أعد إنشاء طرف آخر لنفس المورّد → العملة = USD → حفظ.

    3. انتقل إلى فاتورة الشراء (Purchase Invoice)#

      اختر Alpha Export USD → العملة = USD → اعتماد.

    4. كشف حساب الطرف (Party Account Statement)#

      يعرض الأرصدة بعملتي EUR وUSD جنبًا إلى جنب.
