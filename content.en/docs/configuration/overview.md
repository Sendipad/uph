# Configuration & Governance

UPH provides a centralized settings DocType `Party Master Settings` to manage global behavior.

## Core Settings
- **Override Party Details API**: Injects UPH intelligence into standard ERPNext flows.
- **Enforce Strict Currency Counting**: Prevents cross-currency accounting errors.
- **Sync ERP Party Naming**: Standardizes party naming across all roles.

## Naming Rules
UPH enforces a standardized two-letter capitalized prefix/suffix rule (e.g., `Cu` for Customer, `Su` for Supplier) to ensure consistency across the ecosystem.

## Setup Wizard
The UPH Setup Wizard guides users through the initial configuration of the MDM system, ensuring all core settings are correctly established before production use.
