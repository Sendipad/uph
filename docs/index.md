# Unified Party Hub — Home Page (English)

Welcome to the Unified Party Hub app for ERPNext! This page provides a quick overview, installation steps, key features, and contribution guidelines.

## Overview
Unified Party Hub centralizes the management of parties (customers, suppliers, contacts) in ERPNext, linking documents, accounts, and workflows.

## Key Features
- Unified party record across multiple DocTypes.
- Enhanced search and filters.
- Quick links to related documents (invoices, purchase orders, contracts).
- Customizable settings per company.
- Automated workflows triggered by updates to parties.
